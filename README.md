# 🛡️ 국방·공공 예산안 종합 분석 대시보드 (Defense Budget Analytics Dashboard)

엑셀(`.xlsx`, `.xls`) 및 CSV(`.csv`) 예산 데이터 파일을 입력받아 **분야별**, **신규사업별** 핵심 지표와 증감 추이를 정밀 분석하고 시각화하는 인터랙티브 웹 대시보드입니다.

---

## 🚀 빠른 시작 (실행 방법)

1. **간편 실행**:
   - `web/open_dashboard.bat` 파일을 더블 클릭하거나,
   - `web/index.html` 파일을 웹 브라우저(Chrome, Edge 등)로 엽니다.
2. **추가 설치 불필요**:
   - 별도의 웹 서버나 Python, Node.js 설치 없이 로컬 브라우저에서 100% 동작합니다.
   - 데이터 분석용 라이브러리(`Chart.js`, `SheetJS`)가 로컬 `lib/` 폴더에 번들되어 있어 인터넷 연결 없이도 오프라인에서 완전히 구동됩니다.

---

## 📊 주요 기능

1. **스마트 파일 업로더 (Drag & Drop)**
   - 엑셀(`.xlsx`, `.xls`) 및 CSV 파일 드래그 앤 드롭 지원
   - 열 이름 자동 매칭 (연번, 분야, 세부 사업명, 2026년, 2027년 정부안, 증감액, 증가율, 핵심 내용 등 유연 인식)
   - 한국어 인코딩(UTF-8, EUC-KR / CP949) 및 쉼표 구분 기호 자동 정제

2. **종합 KPI 요약 지표**
   - 2026년 총예산 vs 2027년 정부안 총액
   - 총 증감액(억원) 및 전체 증감율(%)
   - 신규 사업 건수 및 신규 투입 예산 비중

3. **분야별 심층 분석 (Category Analytics)**
   - 중점 영역별 2026 vs 2027 정부안 비교 막대 차트
   - 2027 정부안 분야별 예산 점유율 도넛 차트
   - 분야별 요약 카드 그리드 (클릭 시 해당 분야 사업 즉시 필터링)

4. **신규사업 집중 분석 (New Projects Spotlight)**
   - 전년도(2026년) 예산이 0원이거나 '신규'로 표기된 항목을 자동 판별 (예: **피지컬 AI 실증사업** 등)
   - 신규 사업 전용 하이라이트 배너 및 세부 카드 (예산액, 핵심 추진 내용 등)
   - 기존 사업 vs 신규 사업 예산 구성 비율 파이 차트

5. **인터랙티브 데이터 테이블**
   - 실시간 텍스트 검색 (사업명, 분야명, 비고)
   - 분야별 셀렉트 필터 및 **"⭐ 신규 사업만 보기"** 원클릭 토글
   - 각 열(연번, 사업명, 예산, 증감, 증가율) 오름차순/내림차순 정렬
   - 신규 사업 행 노란색 하이라이트 표시
   - 분석 결과 엑셀(`.xlsx`) 및 CSV 내보내기 기능
   - 기본 제공 6개 항목 샘플 데이터 복원 및 서식 다운로드 기능

## 📁 파일 구조

```
web/
├── index.html                  # 대시보드 메인 웹페이지
├── style.css                   # 대시보드 UI 스타일시트
├── app.js                      # 파싱, 필터링, 차트, 테이블 비즈니스 로직
├── sample_budget_data.xlsx     # 즉시 테스트 가능한 엑셀 샘플 파일
├── sample_data.csv             # 즉시 테스트 가능한 CSV 샘플 파일
├── open_dashboard.bat          # 원클릭 브라우저 실행 배치 파일
└── lib/
    ├── chart.umd.min.js        # 데이터 시각화 라이브러리 (Chart.js)
    └── xlsx.full.min.js        # 엑셀/CSV 파싱 라이브러리 (SheetJS)
```
